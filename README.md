# CampusHub

简洁的个人校园生活入口，本地交互原型。包含科目导航、课程表、任务、校园入口、可选学期档案和科目包。前端使用原生 HTML/CSS/JavaScript；日历解析依赖 node-ical。

ICS 代码生成文件：在「课程表 → 导入课表 → ICS 代码文本」，或「添加课程安排 → 用 ICS 文本生成文件」进入。粘贴已有的 `BEGIN:VCALENDAR … END:VCALENDAR` 完整代码，点击「生成并下载 .ics 文件」即可得到 UTF-8 的 `CampusHub-课程表.ics`。下载直接在当前浏览器完成，无需服务器、日期范围、周次或学校作息，也不会写入课表。仅检查日历首尾标记及 2MB 大小上限，统一为 CRLF 换行；保留已有的时区、重复规则、折叠文本和其他日历组件，不重新解释或生成课程。可接受复制时带有完整 Markdown 代码围栏的 ICS 文本。

如需直接导入 CampusHub，可选择开始和结束日期，点击「预览课表」，沿用现有 ICS 解析服务展开规则、转换北京时间并预览去重，再勾选确认导入。文件生成保留整份原始日历，不受预览日期范围或勾选影响。修改输入会清除旧预览，关闭窗口清空临时文本。原有 URL 与 ICS 文件导入仍保留。测试见 `schedule-text.test.cjs` 和 `campus-flow.test.cjs`。

域名访问：使用 `node server.cjs --public-origin=https://你的域名` 启用精确域名及 HTTPS 来源校验，再通过 HTTPS 反向代理或 Cloudflare Tunnel 连接本机 127.0.0.1:4173。运行与部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。本机部署需要电脑保持开机联网；上传 GitHub 仅保存源码，不会自动部署网站。

界面统一采用莫兰迪配色：暖灰底色、灰玫瑰操作按钮，以及雾蓝、鼠尾草、陶土、灰紫、燕麦五种课程色。颜色集中定义于 style.css 的 CSS 变量，网站卡片与课程表共用同一组色板。普通界面文字（包括卡片和账密显示行）禁止高亮选中；输入框、文本框和可编辑内容保留正常文字选择及编辑行为。

排版与布局：interface.css 集中定义字体、页面密度和响应式布局。桌面首页左侧显示科目，右侧显示今日安排；1279px 以下改为上下排列。主区宽度限制为 1240px，侧栏宽度为 228px，缩短页头及区块留白，科目卡片采用紧凑尺寸。导航统一使用线条 SVG，标题、正文和辅助信息采用明确的字号层级。

手机竖屏：以约 9∶19.5、390×844 CSS 视口为参考，按宽度响应式适配，不限制页面比例或滚动长度。760px 以下启用紧凑顶栏与底部五项导航（首页、课程表、任务清单、校园入口、更多），全部网站、学期档案、科目切换与管理位于「更多」菜单，顶栏标明本机保存。主页、网站和校园入口采用单列，主内容底部留出导航与手势区空间。viewport-fit=cover 与 env(safe-area-inset-*) 处理安全区；输入框使用 16px 字号，弹窗根据 VisualViewport 的可见高度更新上限，应对键盘弹出。课程表在局部区域内左右滑动，表头与课程列共用 694px 最小宽度，页面主体保持自适应。桌面导航与布局保持原来的方式。

字体随项目本地提供，不请求第三方字体 CDN。assets/fonts 中的 Campus Sans 是 Noto Sans SC 的 WOFF2 子集，包含常用 GB2312 一级汉字、界面文字、英文、数字及标点，分别提供常规和半粗两种字重；其他汉字回退至系统中文字体。字体使用 SIL OFL 1.1，版权与许可保留在 assets/fonts/OFL-NotoSansSC.txt，许可来源为 [Google Fonts 字体目录](https://github.com/google/fonts/tree/main/ofl/notosanssc)。如需重建，安装构建工具 fonttools[woff] 后运行 `python scripts/build_font.py /path/to/NotoSansSC-VF.ttf`；这些工具不是网站运行依赖。

首页展示已添加的科目卡片，显示备注和网站数量，点击整张卡片进入对应网站列表，也可直接编辑科目。从首页添加科目后留在首页并立即显示新卡片；没有科目时显示「请添加你的科目」。首次使用不预置任何课程或网站，已有浏览器数据会保留。

自由排序：首页「排序」或「管理课程 → 调整科目顺序」打开科目排序窗口；网站列表的「调整顺序」打开网站排序窗口。电脑可拖动列表行，通过插入标记决定放到目标前面或后面；手机和键盘用户可使用上移、下移按钮。逐次自动保存，关闭窗口保留修改；保存失败会恢复原顺序并提示。科目顺序同时更新首页、侧栏、手机科目菜单和课程管理列表。网站顺序单独记录在 siteOrder，不改写网站创建顺序，所以「名称排序」「最近添加」仍可正常使用；刷新默认采用自定义顺序。搜索或用途筛选后，仅调整当前可见网站，隐藏项保留原位置。排序保留网站 ID、账密密文与任务关联，科目颜色也保持不变。同步码和导入前备份保留自定义网站顺序，科目包和学期快照按手动顺序导出。

今日安排：首页根据现有课程表展示今天尚未结束的课程（包含正在上课的课程）、时间和教室。右侧展示未来七天内截止的任务及所有逾期未完成任务，点击标题编辑，勾选完成，点击关联网站直接打开。没有科目、任务或课表时保留简洁的添加科目引导。提醒在站内显示，页面关闭后不会发送系统通知；时间按北京时间计算。

任务清单：支持添加、编辑、完成、取消完成和删除；可关联科目及该科目的网站，也可创建独立的校园待办。包含截止时间、备注以及待完成、今天截止、近期七天、已完成、全部视图和科目筛选。在科目页可直接添加该科目的任务。科目重命名会同步任务归属，删除科目后任务保留为校园待办。

通知识别：任务清单点击「粘贴通知」，或展开添加/编辑任务窗口的通知栏，粘贴最多 2000 字的原文，点击「一键识别并填入」。仅使用本机规则识别 HTTP/HTTPS、www 和常见域名网址，以及年月日、数字日期、今天/明天/后天、本周/下周星期和中文时刻；无需服务器或 AI 服务。相对日期按北京时间计算，省略年份使用当前年，过去时间会提示核对。优先选择邻近「截止/截至/最晚」等标记的日期；多个不明确的日期提供下拉选择，缺少日期不默认今天，缺少具体时刻暂填 23:59 并提示。识别结果可修改，点击「保存任务」才写入本机；原文保留在备注，多个网址可切换。任务网址独立于已有网站保存并优先用于打开，随同步码、备份和学期归档保留。复杂描述、月底、节假日等未支持的日期需手动填写；这是辅助识别，保存前应核对。

校园入口：独立于科目导航，支持教学教务、图书馆、网络缴费、生活服务、出行、其他分类。自行添加名称、网址和使用说明，可编辑与删除，点击卡片直接打开。初始不添加学校服务的推荐内容。

使用情境：添加或编辑网站时可多选「交作业」「看网课」「查资料」「选课」「其他」，网站卡片显示标签，网站页可按情境筛选，搜索也包含标签。从首页进入科目时会清除之前的搜索和用途筛选。

学期档案：完全手动、可选，不会按日期自动执行。选择要保存的科目和档案名称，默认勾选「保留所选科目在首页」，只创建快照，适合连续学期复用同一课程；取消勾选才将所选科目、网站和相关任务移入档案。快照保留网站、备注、用途、任务及本机网站账密的密文，课程表与校园入口独立保留。可查看历史链接、备注及任务，并选择任意科目复用。同名科目会合并网站，保留当前备注与账密，重复网址跳过。默认不带回旧任务，选择带回时保留原截止时间与完成状态。若归档中的网站 ID 已在其他科目使用，另建入口副本并排除原 ID 绑定的账密，界面会提示重新记录。原档案保留，可反复查看。

科目包：科目卡片上的导出图标或科目页「导出科目包」可下载 JSON，通过文件分享给同学。导出采用字段白名单，仅包含科目名称、颜色、备注及网站名称、地址、用途备注和使用情境；不包含本地空间标识、查看密码、账密密文、任务、课表或档案，并移除网址中常见的 password/token 等查询参数。导入时限制 1MB、100 门科目、1000 个网站，校验文件格式与网址；先预览并勾选科目，再确认合并。同名科目大小写不敏感，重复网址跳过，当前记录不覆盖。导入也采用字段白名单，不接收文件中附加的账密字段。

本地存储：无需注册或登录，也没有账号切换。科目、网站、任务、课程表、校园入口和档案统一保存至当前设备浏览器的 campushub-device-v1 存储项。首次升级时，自动沿用旧版当前选中空间的数据；旧存储仅保留作兼容备份，不合并其他空间的数据。不同设备、浏览器及网站地址各自独立，不会自动同步或上传学习记录到云端。

同步码：电脑侧栏点击「同步码」，手机点击「更多 → 同步码」。来源设备选择「生成同步码 → 复制同步码」，另一台设备选择「读取同步码」，粘贴后点击「读取并预览」。预览展示生成时间、科目名称及各类记录数量；勾选替换确认后才写入本机。搬运内容包括科目及备注/颜色、网站及用途、任务及完成状态、课程表及学期设置、校园入口、学期档案。采用整份替换，不合并两台设备的记录，也不会持续自动同步。

同步码默认携带网站账密密文和查看密码的加密信息，可取消勾选排除所有活动及归档账密。迁移保留网站 ID 和原加密上下文，导入后使用来源设备原来的六位查看密码；不包含明文账密、查看密码或临时密钥。普通数据通过 UTF-8 / Base64URL 编码，未加密，请只传给自己的设备；CRC32 校验仅用于发现复制损坏，不提供身份认证或防篡改保证。格式为 `CHUB1.<数据>.<校验值>`，随记录数量变长，最多支持 2MB 数据；无需服务器保存数据或生成短码。

导入前先将本机完整快照写入 campushub-sync-backup-v1，再替换数据；浏览器存储不足或无写入权限时中止替换。同步码窗口下方「恢复上次导入前的数据」可在刷新或重新打开后继续使用，最多保留最近一次导入前备份。恢复也需勾选确认，之后的本机修改不会保留。清除浏览器站点数据会同时删除内容和恢复备份。同步码读写可在普通 HTTP 局域网页面运行，自动复制不可用时会选中文本供手动复制；查看账密仍需要 HTTPS 或 localhost。

首次运行：`pnpm install --frozen-lockfile`（或使用 npm 安装依赖），然后 `node server.cjs`，访问 http://127.0.0.1:4173 。课程表 URL 导入需要本地服务，不能仅通过双击 HTML 使用。

手机局域网预览：电脑与手机连接同一 Wi-Fi，在电脑另开终端运行 `node server.cjs --lan=电脑的局域网IPv4`，例如 `node server.cjs --lan=192.168.10.221`，手机访问 `http://192.168.10.221:4174/`。局域网模式默认使用 4174 端口，可与 4173 的本机预览同时运行；也可用 `--port=4180` 指定其他端口。只绑定显式指定的私有 IPv4，不自动监听所有网卡，仍校验 Host 和 API 同源请求。需要保持电脑服务运行；更换网络后需使用新 IP 重新启动。Windows 防火墙或校园 Wi-Fi 的设备隔离可能阻止手机连接。不同设备、浏览器及端口使用独立本地存储，科目包可分享科目链接，同步码可手动搬运完整空间；不会自动同步。手机通过普通 HTTP 局域网地址访问时，Web Crypto 账密功能不可用；完整使用需要部署 HTTPS。

功能：课程筛选、搜索、添加/编辑/删除网站、自定义科目与网站顺序、按名称或最近添加排列。网站和课程自动保存至当前浏览器 localStorage。

添加/编辑网站时，名称下方提供 10 个快捷选项：锐捷通、学习通、智慧树、中国大学MOOC、学堂在线、雨课堂、智慧职教、蓝墨云班课、中国知网、智慧高教。支持名称、拼音和别名筛选；仅在显式选择后填写名称与官网，不自动保存网站。名单按大学学习用途选取，不是访问量前十榜单。官方入口与榜单口径的核对记录见 website-research.md（2026-10-23）。测试：`node website-suggestions.test.cjs`。

课程管理：首页「添加课程」可创建课程并设置五种颜色和备注；侧栏「管理课程」可编辑或删除。重命名会更新所有关联网站；删除课程会将网站移至公共资源，保留链接和备注。在课程页添加网站会自动选中该课程。支持同名校验、手机端入口与新课程空状态。

课程表：点击侧栏「课程表」进入七天周视图，支持上一周、下一周、返回本周。先在「学期设置」指定第一周周一及总周数，再添加安排，可填写课程名称、地点、教师、起止时间、颜色和备注，支持每周、单双周和单次日期。点击课表中的课程可编辑、删除。冲突的课程并排显示。课程表安排独立于科目导航，保存在当前浏览器。

课表导入：支持 `http://`、`https://`、`webcal://` 的公开可下载 ICS 日历地址，也可选择 `.ics` 文件。先选择日期范围、读取预览并勾选，再确认合并；不会覆盖现有安排。重复规则、EXDATE 排除日期、RECURRENCE-ID 调课与取消、时区转换由 node-ical 处理；浮动时间按北京时间解释。导入展开为可独立编辑的单次安排，重复导入按 UID/日期与内容跳过，不自动持续订阅、不更新已存在的记录。订阅 URL 仅用于本次请求，不保存至本地数据。

导入限制：单次范围最多约 1 年，文件最多 2MB、最多 2000 节课；全天、跨日及无效时间事件会跳过并报告数量。普通教务登录网页不能直接解析；需要登录态、内网地址或无法公开下载的日历可先导出 ICS 文件导入。URL 读取在本机服务完成，每次重定向重新校验公网地址，固定 DNS 解析结果，限制读取大小和时间；解析在有超时和内存上限的 worker 中进行。示例 `test-fixtures/timetable.ics` 仅用于测试，不会自动导入个人空间。

网站账密：卡片默认显示「账号：******」「密码：******」，眼睛按钮负责验证与显示。首次使用时设置本机共用的六位数字查看密码，再记录网站账密；也可从「详情 → 记录账密/编辑账密」进入。每次查看与编辑都需要验证，显示 30 秒后自动隐藏，再次点击眼睛可立即隐藏。离开页面或切至后台会锁定；编辑窗口 2 分钟超时关闭，关闭时清空输入与临时密钥。

本地加密使用 Web Crypto：PBKDF2-SHA256（600,000 次迭代、随机盐）派生不可导出 AES-GCM-256 密钥，每次加密使用独立随机 IV，并绑定本地加密上下文与网站 ID；旧版记录保留原加密上下文以保证升级后可解密。localStorage 仅保存账密密文、盐及加密验证信息，不保存查看密码、派生密钥或明文账密。需 HTTPS 或 localhost 环境。六位数字的空间有限，不能替代成熟密码管理器的高强度主密码或平台密钥；当前原型未经过安全审计。

忘记查看密码无法恢复已加密记录；清除浏览器站点数据会删除本地内容。目前没有登录、自动跨设备同步或云备份，可用同步码手动搬运与备份。

验证：`node url.test.cjs`、`node --test local-data.test.cjs`、`node vault.test.cjs`、`node vault-flow.test.cjs`。加密与交互测试使用独立内存中的虚构账号和密码，不修改浏览器数据。

全部验证：`node --test *.test.cjs`。课程表测试覆盖手动增改删、单双周、学期边界、重叠布局、导入预览与去重合并、时区/DST、循环/排除/调课/取消、API 来源限制与内网地址拒绝。

同步码验证：`node --test sync-core.test.cjs campus-flow.test.cjs`。使用虚构数据验证完整快照往返、中文与 emoji、活动及归档账密跨设备解锁、损坏/超限/非法数据拒绝、导入预览、输入变更使旧预览失效、确认替换、备份跨刷新恢复、写入失败回滚、取消待完成的导入，以及 HTTP 无 Web Crypto 和复制回退。测试不访问个人浏览器数据。
